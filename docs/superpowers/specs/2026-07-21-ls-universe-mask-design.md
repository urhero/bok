# 상대 모멘텀 유니버스 마스크 (LS Universe Mask) 설계

- 날짜: 2026-07-21
- 브랜치: `feature/ls-universe-mask`
- 상태: 설계 확정, 구현 전

## 동기 (가설)

BM(시총가중) 대비 상대수익률이 좋은 종목은 계속 좋고, 나쁜 종목은 계속 나쁠 것이다.
이 상대 모멘텀을 팩터 랭킹의 "자격 조건"으로 사용한다: 롱 포지션은 아웃퍼폼
종목군에서만, 숏 포지션은 언더퍼폼 종목군에서만 허용한다.

## 접근 방식: 사후 마스크 (승인됨)

현행 파이프라인([1]~[6] 팩터 선정·라벨링·비중 결정)을 완전 무수정으로 유지하고,
종목 비중 전개 단계에서만 유니버스 마스크를 적용한다.

- 대안 비교: 사전 필터(분위 계산 전 유니버스 분리)는 팩터 통계 전면 재계산 +
  섹터 쏠림 정면 노출로 기각. 소프트 오버레이(팩터화)는 기존 Price Momentum
  팩터와의 중복 우려로 기각. 사후 마스크는 효과 분리 측정이 깨끗하고
  (분위가 여전히 섹터 내 순위라 섹터 쏠림이 구조적으로 억제됨) 실패 시 회수 비용 제로.
- 사후 마스크 A/B에서 효과 확인 시 사전 필터 방식을 후속 탐색.

## 1. 유니버스 정의 (매월 재계산)

### BM 차감 제거 (2026-07-21 구현 중 확정)
- 원안은 "시총가중 BM 대비 초과수익"이었으나, **백분위 분할에서는 BM 차감이
  수학적으로 무의미(no-op)** 함이 확인됨: BM은 같은 날짜 모든 종목에 동일한
  스칼라이고, 직후의 횡단면 순위는 행 상수 오프셋에 불변이다.
  (opus 코드리뷰 실증: 시총가중 BM vs 동일가중 BM -> 720/720 분류 동일)
- 상위 X% = BM 대비 상위 X% (동일 집합) 이므로 경제적 의미는 원안과 동일.
- 결정: 백분위 분할 유지 + BM 계산 코드 미보유. 신호 명칭은
  **"횡단면 복합 상대 모멘텀"** 으로 정정. (BM이 의미를 가지려면 절대 임계값
  분할이 필요한데, 유니버스 크기가 시장 국면에 따라 요동쳐 기각)

### 종목별 복합 상대 모멘텀 신호
- 각 horizon h ∈ {1, 3, 6, 12}개월에 대해:
  `신호(h) = 종목 h개월 누적수익률` (log1p 롤링합)
- 각 horizon 신호를 횡단면 백분위 순위(0~1)로 변환.
- 복합 신호 = 가중합, 최근 가중: **1M 0.4 / 3M 0.3 / 6M 0.2 / 12M 0.1**.
- 이력 부족 종목(12개월 미만): 계산 가능한 horizon만 가중치 재정규화하여 사용.
  전 horizon 계산 불가 종목은 **공통 유니버스**로 분류 (fail-open).

### 3분할
- 복합 신호 횡단면 순위 기준:
  - 상위 X% = **롱 유니버스** (숏 금지)
  - 중간 = **공통 유니버스** (양쪽 허용)
  - 하위 Y% = **숏 유니버스** (롱 금지)
- 기본 케이스 30/40/30, 보수 케이스 20/60/20 병행 테스트.

## 2. 마스크 적용 위치

- `construct_long_short_df` 직후 종목 비중 단계에서:
  - 롱 라벨(+1) 종목 중 숏 유니버스 소속 -> 제거, 남은 롱 종목에 동일가중 재분배
  - 숏 라벨(-1) 종목 중 롱 유니버스 소속 -> 제거, 동일 처리
- 엣지케이스: 특정 팩터의 롱(또는 숏) 바스켓이 마스크로 전멸하면 해당 팩터는
  마스크 미적용 유지 + warning 로그 (빈 포트폴리오 크래시 방지).

## 3. Look-ahead 방지

- 신호는 t-1월까지의 수익률만 사용 (팩터 래그와 동일 규약).
- 시점별 trailing window 계산이라 walk-forward에서 별도 IS 규칙 매핑 불필요.

## 4. 설정 (`PIPELINE_PARAMS`)

| 키 | 기본값 | 설명 |
|----|--------|------|
| `universe_mask` | `"off"` | `"off"` / `"on"`. off일 때 기존 출력과 byte-identical |
| `universe_momentum_windows` | `[1, 3, 6, 12]` | 복합 신호 horizon (개월) |
| `universe_momentum_weights` | `[0.4, 0.3, 0.2, 0.1]` | horizon별 가중 (최근 가중) |
| `universe_split` | `[0.3, 0.4, 0.3]` | 롱/공통/숏 비율 |

## 5. A/B 검증 프로토콜

1. `universe_mask="off"` -> 기존 산출물과 byte-identical 확인 (회귀)
2. walk-forward 백테스트 3케이스: off(현행) / on(30/40/30) / on(20/60/20)
3. 비교 지표: OOS CAGR, Sharpe, MDD, Calmar, 턴오버(비용 인지)
4. 섹터 쏠림 실측: 대시보드 섹터 순노출로 마스크 전후 비교
5. 유닛 테스트: 신호 계산, 3분할 경계, 마스크 재분배, 바스켓 전멸 fail-open,
   이력 부족 재정규화

## 리스크 / 참고

- 1M horizon에 0.4 가중은 단기 리버설(1개월 반전 효과)과 충돌할 수 있음.
  A/B 결과가 나쁘면 가중 재조정(예: 1M 축소) 그리드를 후속 검토.
- 마스크는 라벨링 이후 개입이므로 팩터별 롱-숏 수익률 통계(meta_data)와
  실제 보유 종목이 괴리됨 — 진단 시 유의.
